# Biligundulu 
Monthly flow data
website link https://biligundulu.github.io/flow/ 

Biligundulu is the Central Water Commission Hydrological Observation site in the interstate border of Tamil Nadu and Kaveri. This repo contains monthly discharge values since 1992. Discharge is the amount of water that flows thorough the river per second which is then later converted in to per day and then added get monthly. 
The data is obtained through RTI and various other sources.
